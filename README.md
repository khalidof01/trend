# بوت أخبار الجزائر لصفحة فيسبوك

يعمل تلقائيًا على GitHub كل 30 دقيقة، وينشر أخبار المصادر الرسمية (وكالة الأنباء الجزائرية، الرئاسة، الوزارة الأولى، وزارة الدفاع، الإذاعة الجزائرية) على صفحتك.
لا يُنشر الخبر إلا إذا كان رابطه فعلًا من موقع رسمي، وتُتجاهل الأخبار القديمة وغير العربية.

---

## خطوات الإعداد

### 1) رمز صفحة فيسبوك
1. ادخل إلى developers.facebook.com وأنشئ تطبيقًا (نوع Business).
2. من **Graph API Explorer**: اختر تطبيقك، ثم «Get Page Access Token»، وفعّل الصلاحيات:
   `pages_manage_posts` و`pages_read_engagement` و`pages_show_list`.
3. حوّل الرمز إلى رمز طويل المدة (Access Token Debugger ← Extend Access Token)، ثم اطلب `me/accounts` لتحصل على **رمز الصفحة** الدائم و**معرّف الصفحة (id)**.

### 2) (اختياري) مفتاح Claude لصياغة أجمل
من console.anthropic.com أنشئ مفتاح API. بدونه يُنشر العنوان كما هو مع المصدر.

### 3) إضافة الأسرار في GitHub
في المستودع: **Settings ← Secrets and variables ← Actions ← New repository secret**:

| الاسم | القيمة |
|---|---|
| `FB_PAGE_ID` | معرّف الصفحة |
| `FB_PAGE_TOKEN` | رمز الصفحة |
| `ANTHROPIC_API_KEY` | (اختياري) مفتاح Claude |

### 4) تجربة قبل النشر الحقيقي
- في تبويب **Variables** (بجانب Secrets) أضف متغيرًا `DRY_RUN` بقيمة `1`.
- من تبويب **Actions** ← «بوت الأخبار» ← **Run workflow**.
- راجع السجل لترى ما كان سيُنشر. إذا أعجبك احذف المتغير `DRY_RUN`، فيبدأ النشر الحقيقي.

---

## البطاقة المصممة
كل خبر يُنشر مع صورة مربعة فيها العنوان واسم الصفحة والمصدر والتاريخ. لإضافة شعار الصفحة: ارفع صورة باسم `assets/logo.png` (يُفضّل مربعة بخلفية شفافة). الخط المستعمل: Tajawal (رخصة OFL مجانية).

## التعديل
كل الإعدادات في `config.yaml`: المصادر الرسمية، الحد اليومي، المدة بين المنشورات، والوسوم.

## حدود يجب معرفتها
- لا يوجد نظام يضمن صحة الخبر 100%. التطبيق يقلّل الخطأ بقصر النشر على النطاقات الرسمية فقط، لكن راقب الصفحة في الأيام الأولى.
- الأخبار تُجلب عبر Google News، لذلك الرابط في المنشور رابط Google News يحوّل إلى الخبر الأصلي. إن وجدت رابط RSS مباشرًا لوكالة الأنباء ضعه في `direct_feeds`.
- قد يتأخر تشغيل GitHub المجدول بضع دقائق في أوقات الضغط.
