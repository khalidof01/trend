# بوت أخبار الجزائر لصفحة فيسبوك

يعمل تلقائيًا على GitHub كل 30 دقيقة:

- **الأخبار الرسمية** (وكالة الأنباء الجزائرية، الرئاسة، الوزارة الأولى، وزارة الدفاع، الإذاعة الجزائرية): تُنشر **تلقائيًا**، بشرط أن يكون رابط الخبر فعلًا من موقع رسمي.
- **الترندات** (Google Trends الجزائر): تصلك على **تيليغرام** مع المصادر وعلامة ✅ للمواقع المعروفة أو ⚠️ للمواقع المجهولة. تضغط «✅ انشر» أو «❌ تجاهل».

> ملاحظة: الموافقة تُنفَّذ في التشغيل التالي، أي خلال 30 دقيقة على الأكثر.

---

## خطوات الإعداد

### 1) رفع المشروع على GitHub
1. أنشئ مستودعًا جديدًا على github.com (يُفضّل **Public** لأن دقائق التشغيل مجانية بلا حد، والأسرار تبقى مخفية).
2. ارفع كل ملفات هذا المجلد، بما فيها مجلد `.github`.

### 2) رمز صفحة فيسبوك
1. ادخل إلى developers.facebook.com وأنشئ تطبيقًا (نوع Business).
2. من **Graph API Explorer**: اختر تطبيقك، ثم «Get Page Access Token»، وفعّل الصلاحيات:
   `pages_manage_posts` و`pages_read_engagement` و`pages_show_list`.
3. حوّل الرمز إلى رمز طويل المدة (Access Token Debugger ← Extend Access Token)، ثم اطلب `me/accounts` لتحصل على **رمز الصفحة** الدائم و**معرّف الصفحة (id)**.

### 3) بوت تيليغرام (للموافقة على الترندات)
1. افتح @BotFather في تيليغرام واكتب `/newbot` واحصل على **التوكن**.
2. أرسل أي رسالة لبوتك، ثم افتح في المتصفح:
   `https://api.telegram.org/bot<التوكن>/getUpdates`
   وانسخ الرقم الموجود في `"chat":{"id": ...}`؛ هذا هو **معرّف المحادثة**.

### 4) (اختياري) مفتاح Claude لصياغة أجمل
من console.anthropic.com أنشئ مفتاح API. بدونه يُنشر العنوان كما هو مع المصدر.

### 5) إضافة الأسرار في GitHub
في المستودع: **Settings ← Secrets and variables ← Actions ← New repository secret**:

| الاسم | القيمة |
|---|---|
| `FB_PAGE_ID` | معرّف الصفحة |
| `FB_PAGE_TOKEN` | رمز الصفحة |
| `TELEGRAM_BOT_TOKEN` | توكن البوت |
| `TELEGRAM_CHAT_ID` | معرّف المحادثة |
| `ANTHROPIC_API_KEY` | (اختياري) مفتاح Claude |

### 6) تجربة قبل النشر الحقيقي
- في تبويب **Variables** (بجانب Secrets) أضف متغيرًا `DRY_RUN` بقيمة `1`.
- من تبويب **Actions** ← «بوت الأخبار» ← **Run workflow**.
- راجع السجل لترى ما كان سيُنشر. إذا أعجبك احذف المتغير `DRY_RUN`، فيبدأ النشر الحقيقي.

## التعديل
كل الإعدادات في `config.yaml`: المصادر الرسمية، المواقع المعروفة، الحد اليومي، المدة بين المنشورات، والوسوم.

## حدود يجب معرفتها
- لا يوجد نظام يضمن صحة الخبر 100%. التطبيق يقلّل الخطأ بقصر النشر التلقائي على النطاقات الرسمية فقط، لكن راقب الصفحة في الأيام الأولى.
- الأخبار الرسمية تُجلب عبر Google News، لذلك الرابط في المنشور رابط Google News يحوّل إلى الخبر الأصلي. إن وجدت رابط RSS مباشرًا لوكالة الأنباء ضعه في `direct_feeds`.
- قد يتأخر تشغيل GitHub المجدول بضع دقائق في أوقات الضغط.
